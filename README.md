# VelvetMotion AI

**Everything is pushed. The functional site is ready.**

## Run it

```bash
git clone https://github.com/hampusi97/velvetmotion-ai.git
cd velvetmotion-ai
npm install
npm run dev
```

Then open **http://localhost:3000**
