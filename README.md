# VelvetMotion AI

**Ready to deploy. Use the main branch.**

## Deploy to Vercel

1. Go to [vercel.com](https://vercel.com)
2. Import `hampusi97/velvetmotion-ai`
3. Set the branch to **main**
4. Click Deploy

Live URL will be something like: `https://velvetmotion-ai.vercel.app`
